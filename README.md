# Gestor de Reservas de Restaurantes - Cadena Gastronómica

Plataforma web desarrollada en Python y Django orientada a centralizar y digitalizar la administración de disponibilidad de mesas, control de capacidad y gestión de reservas para una cadena de restaurantes.

Este repositorio corresponde a la **Evaluación 1 de Programación Backend**, cuyo propósito es establecer la base técnica del proyecto: configuración de entorno virtual, núcleo de Django, enrutamiento modular, vista de bienvenida y control de respuestas HTTP (error 404 personalizado).

---

## Tecnologías Utilizadas

* **Lenguaje:** Python 3.14+
* **Framework Backend:** Django 6.x
* **Aislamiento de Entorno:** venv
* **Control de Versiones:** Git & GitHub

---

## Requisitos Previos

Asegúrate de contar con lo siguiente instalado en tu sistema:
* Python 3.10 o superior.
* Git.
